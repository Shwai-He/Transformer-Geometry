\section{Introduction}
\label{sec:intro}

Transformer layers evolve representations through learned additive
updates~\citep{vaswani2017attention,elhage2021mathematical} on top of residual
paths~\citep{he2016deep}. Geometrically, each update has two roles relative to
the current representation: a parallel component that preserves direction and a
perpendicular component that redirects it. This view frames representation
evolution as a functional geometry problem: decomposing learned updates into
these roles and testing their behavioral sensitivity under targeted edits.

Our measurements across pretrained models show that learned updates contain
substantial components parallel to the current hidden state. Although a residual
identity path can realize such direction preservation through a simple
operation~\citep{he2016deep,elhage2021mathematical}, the same behavior also
appears inside learned layer updates.

To test whether these components are functionally redundant or behaviorally
important, we apply the decomposition in two settings. In \textit{residual
space}, we edit the updates added back to the hidden state. Given the sequence
modeling inside attention, we also use a \textit{value-space} view of value
aggregation before the output projection, where the self-value contribution is separated from cross-token flow. We then use component-scaling experiments to
modify parallel or perpendicular parts of the update and measure the resulting
degradation.

These edits separate value-space parallel manipulation from its residual-space
analogues. Scaling the part of attention aggregation aligned with the token's own
projected value keeps behavior close to baseline over a broad range. In
contrast, analogous residual-space attention scaling is less stable, residual
MLP-side scaling is more fragile, and perpendicular scaling is much more
disruptive. Together, these comparisons show that robustness is not a generic
property of being parallel: it depends on which representation space defines the
component and which parts of the update are preserved.

We trace this asymmetry to value aggregation inside attention, where the
self-value-aligned contribution can be targeted before projection.
Residual-space analogues instead act after projection against a different
reference, so similar-looking parallel-removal operations can solve different
geometric objectives and produce very different benchmark behavior, including
in settings related to self-directed value flow.

Finally, we test whether this geometry extends beyond inference-time edits.
For compression, we decompose the error between baseline and compressed-model
updates, complementing prior work on post-training compression and
layer-dropping analyses of transformer
redundancy~\citep{Frantar2022GPTQAP,Lin2023AWQAW,Sun2023ASA,men2024shortgpt,He2026UncoveringTR}.
Perpendicular error tracks total compression error closely, while parallel
error is less discriminative; a norm-matched isotropic control shows that much
of this alignment is expected from high-dimensional concentration. We therefore
treat the decomposition as a component-resolved diagnostic rather than a
universally superior compression score. For training, we run from-scratch
pretraining with parallel attention suppression in residual and value spaces.
Across four model sizes and three matched seeds, the value-space variant lowers
fixed-validation loss in all 12 architecture--seed pairs at the final tested
checkpoint. Larger 1.4B and 2.7B single runs also improve average downstream
scores, with the value-space variant giving the largest gain. Together, these
results make editing the central causal analysis and treat compression and
training as supporting applications of the same geometry.

In summary, the contributions of this work are as follows:
\begin{enumerate}
  \item This work reveals substantial direction-preserving components in
        transformer updates and maps their robustness across spaces.
  \item For attention updates, the value-space decomposition separates the
        self-value-aligned direction from the remaining value aggregation,
        explaining the stability gap between value-space and residual-space
        edits.
  \item In compression and training, we test two supporting consequences of
        the editing result: component-resolved error diagnosis and targeted
        self-value-parallel suppression, with claims scoped to the controls and
        runs reported here.
\end{enumerate}
