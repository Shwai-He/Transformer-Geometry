\section{Background}
\label{sec:background}

\subsection{Parallel and Perpendicular Decomposition}
\label{sec:decomp}

Parallel and perpendicular decomposition separates a vector into components
along and orthogonal to a reference direction in the same representation
space. Let $\Delta \in \mathbb{R}^d$ denote the vector being analyzed and let
$\mathbf{z} \in \mathbb{R}^d$ be the reference vector. The unique
components are:
\begin{align}
  \Delta_\parallel
    &= \frac{\Delta \cdot \mathbf{z}}{\|\mathbf{z}\|^2}\,\mathbf{z}
     = \alpha\,\mathbf{z},
     \qquad
     \alpha = \frac{\Delta \cdot \mathbf{z}}{\|\mathbf{z}\|^2},
  \label{eq:para} \\
  \Delta_\perp
    &= \Delta - \Delta_\parallel,
    \qquad \Delta_\perp \perp \mathbf{z}.
  \label{eq:perp}
\end{align}
The parallel component $\Delta_\parallel$ lies along the reference direction
$\mathbf{z}$, whereas $\Delta_\perp$ lies in its $(d-1)$-dimensional
orthogonal subspace and carries the direction-changing degrees of freedom.

This is the basic decomposition used throughout the paper. In residual space,
$\Delta$ is a contribution added to the hidden state; in value space, it
is the value aggregate formed inside attention.

\subsection{Transformer Residual Updates}
\label{sec:transformer}

We consider transformer residual streams with $L$ layers and hidden dimension
$d$. Each residual sub-layer adds an update to the current representation:
\begin{equation}
  \hl{l+1} = \hl{l} + \Dl{l}.
  \label{eq:residual}
\end{equation}
The update $\Dl{l}$ denotes the output of a multi-head self-attention
($\Attn$) sub-layer, a feed-forward ($\FFN$) sub-layer, or the accumulated
attention-plus-MLP contribution. For an individual sub-layer, the reference is
the hidden state immediately before its residual addition. For the joint view,
the reference is the state entering attention and $\Dl{l}$ is the net change
after both attention and MLP. We write $\hz{l}{t}$ for the reference state at
token position $t \in \{1,\ldots,T\}$ and $\Du{l}{t}$ for the corresponding
residual contribution.

For a residual update:
\begin{equation}
  \Dup{l}{t} = \alpha^l_t \hz{l}{t}, \qquad
  \alpha^l_t = \frac{\Du{l}{t}\cdot \hz{l}{t}}{\|\hz{l}{t}\|^2}.
\end{equation}
Adding the parallel component therefore rescales the existing hidden state by
$1+\alpha^l_t$. The resulting representation is
\begin{equation}
  \hz{l+1}{t}
  = (1+\alpha^l_t)\hz{l}{t} + \Duperp{l}{t}, \qquad
  \Duperp{l}{t}\perp \hz{l}{t}.
\end{equation}

To measure update geometry, we report the relative magnitude
$\|\Dup{l}{t}\|/\|\Duperp{l}{t}\|$ across layers. This ratio quantifies how
much update magnitude lies along the current representation versus orthogonal
directions; the sign of $\alpha^l_t$ indicates whether the parallel component
points with or against the current representation.

Figure~\ref{fig:profiles} reports this ratio across generation steps at three
sampled layers for two Qwen3 models. The persistent parallel components
motivate us to ask when they affect model behavior and in which representation
spaces those effects are robust.
