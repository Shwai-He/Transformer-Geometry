\section{Attention-Diagonal Editing Details}
\label{app:method}

\paragraph{Attention-diagonal editing.}
This appendix gives the general per-query attention-aggregation form behind the
diagonal implementation in \S\ref{sec:closed-form-control}. For an update,
\[ 
  \mathbf{y}_t=\sum_{s\le t} A_{ts}\mathbf{m}_s,\qquad
  \mathbf{y}_{t,\parallel}
  =
  \frac{\mathbf{y}_t^\top\mathbf{r}_t}{\|\mathbf{r}_t\|^2}\mathbf{r}_t .
\]
Keeping off-diagonal weights fixed, a diagonal edit gives
\(\widetilde{\mathbf{y}}_t=\mathbf{y}_t+\Delta A_{tt}\mathbf{m}_t\). Scaling
the projection of \(\mathbf{y}_t\) along \(\mathbf{r}_t\) by \(s\) therefore
requires
\[
  \Delta A_{tt}
  =
  (s-1)
  \frac{\mathbf{y}_t^\top\mathbf{r}_t}
       {\mathbf{m}_t^\top\mathbf{r}_t}.
\]
Table~\ref{tab:effective-diagonal-derivation} applies this expression to the
raw value-space edit and contrasts it with the residual-space attention edit.
For the exclude-self variant used in our primary value-space results,
Eq.~\ref{eq:exclude-self-scaling} instead applies the projection to
\(\sum_{s<t}A_{ts}\mathbf{v}_s\) and then restores the unchanged direct term
\(A_{tt}\mathbf{v}_t\).

\paragraph{Residual-space diagonal coefficients.}
The residual-space diagonal form differs because changing \(A_{tt}\) moves the
output along \(W_O\mathbf{v}_t\), while the residual-space reference direction
is \(\hz{}{t}\). For removal,
\[
  \Delta A^{\mathrm{res}}_{tt}
  =
  -
  \frac{(\Delta_t^{\Attn})^\top\hz{}{t}}
       {(W_O\mathbf{v}_t)^\top\hz{}{t}} .
\]
The numerator is the unnormalized residual-space parallel coefficient of
\(\Delta_t^{\Attn}\); the denominator measures how much the self-value message
can move the output along the same residual direction.

Small magnitude does not make the edit equivalent to value-space manipulation. The
value-space objective acts on the component along \(\mathbf{v}_t\), whereas the
residual-space objective, when pulled back through \(W_O\), acts on the
component along \(W_O^\top\hz{}{t}\):
\[
  (\Delta_t^{\Attn})^\top\hz{}{t}
  =
  \mathbf{o}_t^\top W_O^\top\hz{}{t}.
\]
In general \(W_O^\top\hz{}{t}\) is not parallel to \(\mathbf{v}_t\). Therefore,
the residual-space attention edit solves a different scalar constraint from
value-space self-value-parallel manipulation. Across a sequence, each token
has its own \(\mathbf{v}_t\), \(\hz{}{t}\), and pulled-back reference
\(W_O^\top\hz{}{t}\), so the residual coefficients do not implement one
uniform scale on the value-parallel component. Compared with pure
value-space parallel scaling, the residual-space edit therefore introduces
additional motion in directions perpendicular to the self-value direction. The
benchmark experiments indicate that this extra directional perturbation can be
harmful even when the diagonal coefficients themselves are small.

\paragraph{Forward-hook implementation.}
The experiments implement component scaling by replacing the selected tensor
during the forward pass. In code, the same operation can be written as
\begin{align*}
  \mathbf{y}_{\parallel} &= \frac{\mathbf{y}^{\top}\mathbf{r}}{\|\mathbf{r}\|^2}\mathbf{r}, \\
  \mathbf{y}_{\perp} &= \mathbf{y}-\mathbf{y}_{\parallel}, \\
  \widetilde{\mathbf{y}} &= (1-\alpha)\mathbf{y}_{\parallel} + \sperp\mathbf{y}_{\perp}.
\end{align*}
Thus \(\alpha=0\) recovers the unedited tensor, \(\alpha=1\) removes the
parallel component, and changing \(\sperp\) scales only the perpendicular
component. For residual-space attention edits, \(\mathbf{y}\) is the attention
branch output after \(W_O\), before residual addition, and \(\mathbf{r}\) is
the hidden state entering the attention block. For residual-space MLP edits,
\(\mathbf{y}\) is the MLP branch output and \(\mathbf{r}\) is the hidden state
entering the MLP sublayer. For value-space edits, \(\mathbf{y}\) is the
attention aggregation before \(W_O\), and \(\mathbf{r}\) is the token's own
value vector. In multi-head attention, grouped key-value heads are first
expanded to the output-head layout and then concatenated. The value-space edit
is applied jointly to the complete pre-\(W_O\) value representation for each token.
This implementation preserves the ordinary output projection and
changes only the parallel/perpendicular composition of the vector passed into
\(W_O\). Table~\ref{tab:projection-overhead} reports measured costs.

The implementation fuses the dot product, norm, and projection update into one
GPU kernel without changing the mathematical intervention. Inference modes are
interleaved across repeated rounds in one allocation with FlashAttention-2.
Decode uses a preallocated static KV cache, CUDA Graph replay, and CUDA Event
timing, so its result applies to fixed batch and shape rather than dynamic
generation. Training uses a stride-aware analytic-autograd kernel. All measured
paths retain baseline peak allocation. Measurements use one RTX 6000 Ada with
PyTorch 2.5.1+cu121, CUDA 12.1, and Transformers 4.52.4. Thus the projection has
measurable but modest cost; we do not describe it as zero-overhead.

\paragraph{Edit settings.}
All inference edits are applied during the forward pass and leave weights
unchanged. The retained-scale value-space benchmarks edit every decoder layer
except the first. Residual-space controls use their recorded layer ranges. The
value-space edit decomposes the pre-\(W_O\) attention aggregation relative to
the token's own value vector, whereas residual-space edits decompose the
post-\(W_O\) attention output or MLP output relative to the incoming hidden
state. Scaling sweeps vary one of \(\spara\) or \(\sperp\) while keeping the
other fixed at 1; benchmark tables use the settings specified in their
captions.

\paragraph{Head-level localization.}
\label{app:head-localization}
We test whether the value-space effect is localized to particular heads or
depths by extending the full-removal diagnostic to every decoder layer of four
Qwen3 scales. On the same 128 fixed C4 texts, each layer contributes every
isolated query-head edit (16 heads for 0.6B and 1.7B; 32 for 4B and 8B) and one
joint all-head edit. Figure~\ref{fig:per-head-causal-sensitivity} includes every
head in the blue envelope, without significance-based selection. Layer 0 is an
exceptional positive joint outlier at every scale. Beyond layer 0, the joint
effect changes sharply with depth and often leaves the corresponding
single-head range. Thus the early/middle/late snapshots are not three smooth
stages: individual layer choice can expose qualitatively different behavior,
and the simultaneous intervention is strongly non-additive.

\section{MLP-Internal Geometry Diagnostic}
\label{app:mlp-internal-carrier}

For a gated MLP, let $x$ be the MLP input, $h$ the post-gating intermediate
state, and $y=W_{\mathrm{down}}h$ the MLP output. We partition $h$ into
hidden-width groups $h_g$. In the grouped $h$--$x$ diagnostic, each $h_g$ is
decomposed relative to $x$, the edited groups are concatenated, and
$W_{\mathrm{down}}$ is applied once. In the grouped $h$--$y$ diagnostic, each
projected contribution $y_g=W_{\mathrm{down}}[:,I_g]h_g$ is decomposed
relative to $h_g$ under an explicit coordinate identification. The latter is
the closest MLP analogue to value-space geometry, but it remains an empirical
coordinate diagnostic rather than a claim that intermediate and residual
bases have identical semantics.

On Qwen3-0.6B, all hooks exactly match baseline at the no-op setting over
32,704 fixed C4 tokens. Table~\ref{tab:mlp-internal-carrier} compares full
parallel and perpendicular removal with the residual-space MLP control.

\paragraph{Relation to layer-drop cosine.}
The parallel/perpendicular view also explains a common layer-drop diagnostic
\citep{He2026UncoveringTR}.
Let \(x\) be the incoming representation and let a layer update decompose as
\(\Delta=\Delta_{\parallel}+\Delta_{\perp}\), with
\(\Delta_{\parallel}=\alpha x\) and
\(\|\Delta_{\perp}\|=\beta\|x\|\). Then
\begin{align*}
  \cos(x,x+\Delta)
  &=
  \frac{1+\alpha}
       {\sqrt{(1+\alpha)^2+\beta^2}} \\
  &=
  \frac{1}
       {\sqrt{1+\left(\frac{\beta}{1+\alpha}\right)^2}},
\end{align*}
assuming \(1+\alpha>0\). Therefore the usual layer-drop quantity
\(1-\cos(x,x+\Delta)\) is a monotone function of
\(\beta/(1+\alpha)\), and for small angles is approximately
\(\frac{1}{2}\left(\beta/(1+\alpha)\right)^2\). In this sense, layer-drop
cosine summarizes two geometric quantities: the perpendicular update ratio
\(\beta\) and the parallel rescaling \(1+\alpha\). It assigns larger relevance
to layers whose updates induce a larger relative deviation from the incoming
direction. Increasing \(\beta\) directly enlarges this deviation, while
\(1+\alpha\) sets the residual scale in the denominator. A larger positive
\(\alpha\) therefore reduces the effective perpendicular ratio, whereas a
negative \(\alpha\) increases it. This interpretation is consistent with our
view that perpendicular components drive representation evolution, while
parallel components modulate the scale against which this directional change is
measured.
Figure~\ref{fig:baseline-update-over-hidden} shows the baseline-update
magnitude that supports this interpretation.

  \caption{\textbf{Baseline layer updates are small relative to the residual
  stream.}
  The uncompressed update magnitude \(\|\Delta\|/\|x\|\) remains well below
  one across layers and branches. Since the parallel coefficient \(\alpha\)
  controls the residual rescaling term \(1+\alpha\), layer-drop cosine reflects
  the effective perpendicular ratio \(\beta/(1+\alpha)\), not \(\beta\) alone.}

\end{figure}

not establish that perpendicular error universally outperforms total error.
