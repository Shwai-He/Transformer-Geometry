\section{Related Work}
\label{sec:related}

\paragraph{Residual-stream geometry and residual scaling.}
Residual connections preserve the input representation while allowing each
block to add a learned transformation~\citep{he2016deep}. In transformers, this
creates a residual stream that carries information across layers and serves as
the workspace for attention and feed-forward
updates~\citep{elhage2021mathematical}. This preservation path is also a practical
target for architectural scaling mechanisms: ReZero~\citep{Bachlechner2020ReZeroIA},
LayerScale~\citep{touvron2021going}, and deep-transformer initialization or
normalization schemes~\citep{xiong2020on,Wang2022DeepNetST} adjust residual
branch scale to improve optimization and stability. Residual paths can also
mitigate degeneracy in deep self-attention, including rank
collapse~\citep{dong2021attention}. These works establish the importance of
residual pathways and residual magnitude. We study a complementary geometric
property of the learned update itself: whether it preserves the current
direction or rotates the representation into a perpendicular component.

\paragraph{Context modeling and attention geometry.}
Attention explicitly aggregates information across
tokens~\citep{vaswani2017attention}, but attention mass can also concentrate
on special or persistent positions, as shown by attention-sink behavior in
long-context inference~\citep{xiao2023efficient}. Gated attention variants
mitigate such sink behavior by modulating attention
outputs~\citep{qiu2025gatedattention}. However, even when attention sinks are reduced,
large diagonal attention weights can still route substantial mass back to the
current token itself. Exclusive Self-Attention (\xsa{}) directly addresses this
self-directed pathway by modifying value flow aligned with the current
token~\citep{zhai2025xsa}. We revisit this issue from a
parallel/perpendicular geometric perspective, focusing on when attention
updates preserve the current direction and when they introduce
direction-changing information.

Activation steering instead adds a task- or contrast-derived vector to a
residual-stream activation to control model behavior~\citep{turner2023activation}.
Our intervention is not defined by a target behavior or contrastive prompt: it
uses the model's current hidden state or self-value as an endogenous reference
and scales the analytically determined parallel and perpendicular components.
