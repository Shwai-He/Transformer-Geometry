# Legacy Outputs Compatibility Layer

This directory is retained only for older value-pre scripts that previously wrote under `outputs/<model>/value_pre_ratio/`.

Canonical locations now live under:

- `results/value_pre_ratio/`
- `results/value_pre_ratio_logs/`
- `results/value_pre_prompt_shards/`

Where possible, prefer the `results/` tree for new runs.
